# Kripto Klasik
Kalkulator enkripsi dan dekripsi algoritma kriptografi klasik berbasis web.

## Algoritma
- Vigenere Cipher
- Affine Cipher
- Playfair Cipher
- Hill Cipher
- Enigma Cipher

## Quick Start
``` bash 
git clone https://github.com/nanditoadi/crypto-klasik.git
```

``` bash
cd crypto-klasik
```

``` bash 
pnpm install 
```

``` bash
pnpm run dev
```
---
Buka `` http://localhost:3000 ``
